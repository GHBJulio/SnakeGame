# Snake Game Project by Guilherme Julio

## Project Description

This project implements a classic Snake Game using Java and JavaFX. It features a player-controllable snake, various obstacles, and items that enhance or challenge the gameplay. The game is designed to provide an entertaining and nostalgic gaming experience.

## Installation and Running

To run the Snake Game, follow these steps:

1. Download and unzip the project folder.

2. Open the project in your preferred Java development environment (e.g., IntelliJ IDEA, Eclipse).

3. Ensure that your Java SDK is version 20 or higher.
 
4. Run the SnakeGameApp.java file to start the game.

## How to Play
* Control the snake using arrow keys to navigate.
* Collect food items to grow the snake and increase the score.
* Avoid collisions with obstacles and the snake's own body.
* Special items may appear, offering unique effects.
